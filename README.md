# Accredian Enterprise - High-Performance Learning Platform

Accredian Enterprise is a production-grade, AI-first enterprise learning platform designed to help organizations upskill their workforce in Data, AI, and Product. Built with Next.js 15, Tailwind CSS 4, and Framer Motion.

## 🚀 Features

- **Premium UI/UX**: Modern, glassmorphism-inspired design with smooth micro-animations.
- **Dark/Light Mode**: Fully responsive theme support using `next-themes`.
- **High Performance**: Optimized image handling, lazy loading, and minimal bundle size.
- **SEO Optimized**: Comprehensive metadata, OpenGraph tags, dynamic sitemap, and semantic HTML.
- **Interactive FAQ**: Smooth accordion-style FAQs for quick support.
- **Lead & Query Capture**: Integrated APIs for enterprise lead generation and user queries.
- **Dockerized**: Production-ready Docker setup for easy deployment.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Validation**: [Zod](https://zod.dev/)

## ⚙️ Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/amankumarvishwakarma767/accredian-enterprise-clone.git
   cd accredian-enterprise-clone
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

## 🌐 Deployment (Vercel)

1. Push your code to GitHub.
2. Import the project into **Vercel**.
3. Vercel will automatically detect the Next.js settings.
4. Add any environment variables if needed.
5. Deploy!

## 🐳 Docker

1. **Build**: `docker build -t accredian-enterprise .`
2. **Run**: `docker run -p 3000:3000 accredian-enterprise`

## 🔄 Development Workflow

1. **Branching**: Create a feature branch for new changes.
2. **Linting**: Run `npm run lint` before committing.
3. **Building**: Ensure `npm run build` passes locally.
4. **Pushing**: Push to `main` branch for automatic Vercel deployment.
